# Verification artifacts

The repository publishes the final, current artifacts under `reports/`:

- `reports/local_2025_final.json`: full 2025 report with 1,000 resamples.
- `reports/overview.png`, `boundary.png`, `missing_scenarios.png`: native tkinter screenshots.
- `reports/NOIP局部标定_2020.txt` … `2025.txt`: exported text reports.

Running `verify_local_gui.py` locally creates `verification/gui/`; that directory is ignored because it is regenerable. Early snapshots have been removed.
