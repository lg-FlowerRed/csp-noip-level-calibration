# CSP-S / NOIP 边界成绩标定

用同年同人的 CSP-S 与 NOIP 获奖成绩，估计 **CSP-S 6/7 级分数线附近的选手在 NOIP 中的典型表现**，并换算为全国累计比例参考值。

> **这不是 CCF / NOI 官方项目。** 所有输出都是统计估计，不构成评级依据，不预测任何个人等级，也不得用于升学、申诉或竞赛资格判断。

## 它回答什么问题

CSP-S 的“前 15%”和 NOIP 的“前 15%”不是同一难度：NOIP 选手是从 CSP-S 参赛者中选拔出来的。这个项目不猜“难度比 D”，而是直接看真实数据：

1. 同一年、同一名选手在 CSP-S 和 NOIP 的成绩；
2. 在 CSP-S 等级线附近，这些选手的 NOIP 成绩分布；
3. 达到某条 NOIP 分数线的人，占全国 NOIP 实际参赛人数的多少。

## 三个必须区分的概念

| 概念 | 含义 | 能说明什么 |
|---|---|---|
| **可见基线** | 两场均获奖且身份匹配成功的选手，在边界处的局部中位数 | 已知获奖样本的典型表现；不是全体参赛者 |
| **校正候选** | 用官方省级获奖门槛拟合截断分布后，对完整边界人群的模型估计 | 依赖分布假设；未通过验证时只作候选 |
| **采用判断** | 学校分组验证＋独立遮挡回测＋稳定性检查 | 决定哪一栏作为主显示，不把两者强行平均 |

三种不确定性分开报告，不能混用：

1. 同分范围（固定分数线的严格高于/包含同分计数）；
2. 固定模型的学校整组重抽区间；
3. 模型选择与未知低分比例 π 的敏感性（**不是** 95% 置信区间）。

## 快速开始

### 环境

- Windows（GUI 与 `.bat` 启动脚本为 Windows 专用；核心 CLI 在其它系统也可运行）
- Python 3.12，包含 Tcl/Tk
- NumPy、SciPy

```bash
py -m pip install -r requirements.txt
```

### 图形界面

双击 `run_gui.bat`，或：

```bash
py calc_rating_gui.py
```

输入年份与 CSP-S 6/7 级累计比例（例如 `15` 和 `7.5`），点击“开始标定”。

### 命令行

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 1000
```

只做快速计算、跳过重抽：

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 0
```

导出完整 JSON（拒绝覆盖已有文件）：

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 1000 --json --output result.json
```

## 数据

本仓库**不包含**完整获奖名单与学校别名表：

- `data/raw.txt` 含获奖者姓名、学校、年级、分数等可识别个人信息，尤其涉及未成年人；
- `data/school.txt` 与部分辅助 JSON 来自上游数据集，许可需单独核实。

仓库仅包含**无个人信息的聚合数据**：

| 文件 | 内容 |
|---|---|
| `data/contests.json` | 赛事年份、满分、全国实际参赛人数 |
| `data/province_cutoffs.{json,csv}` | 官方公布的分省获奖分数线与人数（含来源 URL） |
| `data/province_quotas.json` | NOIP 分省参赛名额 |
| `data/province_participants.csv` | 名额上限与按全国比例分摊的估算（非官方分省人数） |
| `data/province_awards_from_raw.csv` | 逐省逐奖人数、实际最低/最高获奖分（无姓名） |
| `data/分省数据说明.md` | 口径、来源、缺口与限制 |

要运行完整分析，请自行从 NOI 官网获取获奖名单与学校别名表，并按 `data/README.md` 的格式放入 `data/`。缺少这些文件时，真实数据集成测试会自动跳过，合成数据测试仍可运行。

## 方法概要

1. 用全国 CSP-S 实际参赛人数与完整获奖名单确定 6/7 级锚点（同分不拆分）。
2. 在锚点附近取 ±1/2/3/5 个百分点的局部窗口，拟合非负斜率局部中位数线，得到**可见基线**。
3. 以各省官方获奖门槛为观察规则，对原始 NOIP 分数拟合有界正态与厚尾 t(5) 截断分布，得到**校正候选**。
4. 留出 1/5 学校作独立审计，其余学校内三折选择分布与窗口；在审计集上做人工遮挡，比较逐人中位数预测的 MAE。
5. 仅当预设的改善、样本量、分布稳健性与计数完整性条件全部通过时，才采用校正作为主显示。

## 示例结果（2025，CSP-S 6级15%、7级7.5%）

| 级别 | 可见基线 | 校正候选 | 是否采用校正 |
|---|---:|---:|---|
| 6级 | 33.69% | 37.20% | 否 |
| 7级 | 22.31% | 30.21% | 否 |

## 已知限制

- 未获奖者没有身份和具体分数，真实等级线以下的分布无法由现有资料非参数识别。
- 未匹配记录不等于“未参赛”或“未获奖”，程序不会把它们填成 0 分。
- 省级获奖门槛不同，候选线以下可能仍有强省未获奖者；计数完整性依赖门槛覆盖。
- 仅建模局部常数尺度，未加入无法可靠标准化到总体的省份/年级随机效应。
- 某省内只有一所学校时，该层无法估计组间重抽方差；若所有层都如此，程序不报告区间。
- 各年独立标定，不混合不同年份的原始分数。
