# 当前数据下的 NOIP 6/7 级局部标定改进方案

日期：2026-11-14。**实施状态：已完成 v3.0-local。** 程序入口为 `calc_rating_matched.py` 和 `calc_rating_gui.py`，使用 `rating_records.py` 与 `rating_local.py`；使用方法见 [安装与使用说明](install-windows.md)。

当前实现的重要口径：

- 主样本始终严格匹配，模糊匹配仅作敏感性；不读取名额或分省人数估算作分母。
- 局部线性中位数、有界正态/厚尾 t(5) 截断拟合、学校分组验证、缺失π情景及学校整组重抽均已实现。
- 遮挡采用检验以**同一审计选手的实际 CSP-S 分数和原门槛**计算逐人条件中位数预测 MAE；局部截距只作描述，不比较不同门槛混合中位数与 LAD 截距。
- 当前采用局部常数尺度，未加入无法可靠标准化到总体的省份/年级随机效应；省份作为门槛及影响诊断。固定模型重抽区间不含模型选择误差，模型敏感性另列。
- 零获奖省份也纳入门槛覆盖核验；未知门槛不当作零。省内全部只有一所学校时，不报告虚假的零宽重抽区间。
- 两级锚点若落入同一个 CSP-S 同分块，复用同一标定与区间，保证同分同线。

下文保留方案论证；其中“本轮实际检查”的窗口中位数是设计阶段诊断，不是新版正式运行结果。正式样例见 [2025年完整报告](../reports/local_2025_final.json)。


## 一、结论与适用范围

建议把当前“全局平均百分位等张映射”改为：

> **边界局部标定＋省别获奖截断校正＋人工遮挡回测＋分开报告模型与缺失不确定性。**

目标不是收齐所有人的两场成绩，而是最大化利用现有的同年配对成绩、全国总人数和已核实的官方获奖线。各省实际参赛人数不是前置条件，名额和按全国获奖率分摊的省人数不进入主估计。

不能保证在所有未知真实分布下都有一种“最准确”的算法：NOIP 未获奖者没有身份和分数，等级边界处的未获奖比例无法由现有资料非参数地唯一确定。新方案的目标是在明确假设下减少可纠正偏差，并通过现有数据检验这些假设能检验的部分；不能把无法检验的部分藏在一个精确数字里。

## 二、统一要估计的对象

以“CSP-S 边界选手在 NOIP 中的典型表现”作为主口径。

对年份 t、等级 k：

1. 用全国 CSP-S 实际参赛人数和完整获奖名单，确定目标累计比例对应的分数线 `c_S,k`，同分者不拆分。
2. 在当年两场都实际参加、具有有效 CSP-S 成绩的选手中，定义：

   `c_N,k = Median(NOIP成绩 | CSP-S成绩 = c_S,k，实际参加当年NOIP)`。

3. 得到 NOIP 候选分数线后，计算：

   `q_N,k = 全国NOIP成绩≥c_N,k的人数 / 全国NOIP实际参赛总人数`。

使用中位数，是因为它直接回答“边界处的典型选手考多少”，并最小化绝对预测误差；这是一项合理的技术约定，不是被数据证明的唯一政策定义，也不等于已完成潜在能力的严格考试等值。

主模型和对照模型必须估计上述同一对象。“使两场等级判定错误率最小”的分类线是另一个对象，仅作另栏展示，不能因二者相差超过固定百分点就认定原始数据质量差。

## 三、现有程序中应改变的处理

### 1. 官方线与实际最低获奖分分开

当前 `calc_rating_matched.py` 的 `safe_observation_score()` 使用“各省实际最低获奖分的最大值”。这可能因小省某个分数段没人而被抬高。

根据目前本地保存的 2025 年官方线表：

| 项目 | CSP-S | NOIP |
|---|---:|---:|
| 程序由实际最低获奖分推得的全国安全线 | 57 | 93 |
| 已收录官方各省最低获奖线的最大值 | 30 | 86 |

官方线应先核对年份、省份、奖项、资格和规则含义。只要这些条件覆盖一致、分数达到该线就保证入名单，官方线以上的人数可以直接清点。不能把未公布的线当作 0，也不能把实际最低获奖分当作官方线。

### 2. 不按 NOIP 分数再次大批删掉真实配对

“分数线以上人数能完整清点”和“边界选手的典型成绩能无偏估计”是两件事。

把所有低于全国最高观测线的配对删除，可以让剩余点的全国排名容易计算，却会进一步只留下 NOIP 发挥好的人。它不能消除获奖选择偏差。

新模型直接拟合已知的 **NOIP 原始分数**，不是低分区不完整的全国百分位。经核实的低分获奖配对仍有信息，应保留并使用各自省份的观测阈值处理。仅在最后换算全国比例时才要求候选线以上人数完整。

### 3. 不把未匹配者填成 0 分

CSP-S 记录在 NOIP 获奖名单中没有匹配项，可能是未参赛、未获奖或身份字段不同。没有证据时全部标“NOIP状态未知”，不纳入任何一种确定标签。

主分析使用严格身份一致及可核验学校别名匹配；模糊配对单独做纳入/排除敏感性。相似度分数不是经过校准的真实匹配概率，不用它随机制造“置信度”。

## 四、推荐的计算步骤

### 第一步：固定全国 CSP-S 锚点

- 分母继续使用 `contests.json` 的全体 CSP-S 第二轮人数；不因为 NOIP 主要为高中生就暗中改成高中生获奖人数。
- 按全国分数排序定位 6/7 级线；记录严格高于、等于及包含同分的人数。
- 用官方省级最低获奖线验证该锚点是否完整可观测；若不能确认，输出锚点范围而不是伪造精确排名。
- 2020–2025 每年独立处理；2019 和未举行的 NOIP2026 不做同年映射。

### 第二步：在边界附近找人，而非用全部达标者平均值

以每个等级的 CSP-S 同分块中点百分位为中心，候选半带宽为 1、2、3、5 个百分点。

窗口中心权重大，离边界远的权重小。用局部线性项处理窗口左右不对称，避免“窗口里高于等级线的人更多”把中心估计带偏。带宽通过回测选，不通过看哪个结果更顺眼来选。

仅剔除可确认的数据错误、重复记录和身份冲突；真实的临场失误也是考试表现的一部分，不因两场成绩差距大就删除。

### 第三步：建立考虑获奖门槛的局部条件分布

**数据是截断，不是通常意义的删失**：很多未获奖选手连一整条 NOIP 记录都没有；程序并不知道每个未匹配 CSP-S 选手是否参加过 NOIP。因此不能直接给每人补一个“低于获奖线”的标签，套用普通 Tobit 删失回归。

对已经配对的选手 i，设：

- `x_i`：CSP-S 原始分数；
- `y_i`：NOIP 原始分数；
- `a_p`：该省该年的有效最低获奖门槛；
- `fθ(y|x)`、`Fθ(y|x)`：实际 NOIP 参赛者的条件成绩分布。

若观察机制确为 `y_i≥a_p`，其观察到的条件密度为：

`fθ(y_i|x_i) / [1 - Fθ(a_p^-|x_i)]`。

局部拟合使用上述**截断似然**，而不是把可见获奖者当成全体直接拟合。若边界有同分或整数分数，则对相应分数格积分计算概率；边界是否包含按原规则处理。

主候选模型保持简洁：局部位置随 CSP-S 分数单调变化，尺度允许有限变化；比较自然满分区间内归一化的正态分布和固定自由度厚尾 t 分布。只在按学校分组的验证确实改善时，加入收缩的省份/年级效应，避免几千条数据拟合大量参数。

关键假设必须写明：

1. 官方获奖门槛准确描述进入可见名单的机制；特殊奖项/类别不能套错门槛。
2. 给定 CSP-S 成绩及模型纳入的分层因素后，选择的分布族能合理描述 NOIP 表现。
3. 高可信身份匹配仍缺失的部分，不能与 NOIP 发挥存在模型未处理的强关联。
4. 若引入省份效应，全国边界人群的省份构成不能直接用获奖份额、名额或全国平均率冒充。可在模型假设下由观测概率校正估计，并另做不校正/部分校正敏感性；无任何样本的群体无法凭空恢复。

从拟合的完整条件分布取中位数，得到 NOIP 候选线。两级使用一致的单调结构，保证更高等级不对应更低分数线。若必须依靠明显超出样本支持的外推，报告失败，不机械裁剪出一个合法数字。

### 第四步：给出不依赖尾部分布形状的缺失敏感性

不能把截断校正模型当作已知真相。为此，另用一条易解释的公式直接展示缺失影响。

在共同安全门槛 `a` 以上，设边界附近已观测成绩的分布为 `G`，实际边界 NOIP 参赛者中位于 `a` 及以下的未知比例为 `π`。若身份缺失可以忽略，且 `π<50%`，那么完整人群的中位数是可见分布的：

`G⁻¹((0.5 - π) / (1 - π))`。

例如 `π=20%` 时，应取可见分布第 37.5 百分位，而不是可见获奖者的中位数。若 `π≥50%`，完整中位数落到门槛以下，无法只凭可见尾部定位具体分数。

截断回归给出的是**基于分布假设的 π 估计**。同时显示 π=0%、10%、20%、30%、40% 等明确标注的情景曲线/表，不能把这些情景称作已测得的未获奖率或 95% 置信区间。

全国未获奖比例也不能直接当作等级线附近的 π；“NOIP 获奖者未匹配率”同样不是 π。

### 第五步：将分数线换算为全国比例

- 若 `c_N` 以上全国成绩记录在已核实的规则下完整：直接计算 `count(Y≥c_N)/N_NOIP`，这是固定分数线下的计数结果。
- 展示完整同分范围；如模型线落在两个实际分值之间，明确采用“成绩≥模型线”，不随意改选一个更低分数来凑比例。
- 若 `c_N` 落到未观测区：只给已知达标人数下界及真正可证明的计数范围；不要把局部修正模型的不确定性误称为全国比例的有限保守上界。
- 不使用各省名额作分母，不使用 `province_participants.csv` 中按全国获奖率分摊的估算。

## 五、如何只用现有数据检验改进

### 1. 人工遮挡回测——最重要的新增验证

先把目前已观测的配对队列作为一个已知参考人群，再人为提高其 NOIP 可见门槛，把原本可见的低分部分藏起来。

比较两个方法能否从剩余高分人群恢复这个**已知参考队列**的边界中位数：

- 对照：直接用剩余人群的局部中位数；
- 新方法：使用人为提高的门槛进行截断校正。

可模拟不同省份门槛及 10%/20%/30% 的额外遮挡。在样本支持范围内重复多次，检查分数线误差和最终比例百分点误差。

必须注意验证目标：如果原始数据本来已在门槛 a 以上截断，回测真值只能是“Y≥a 的参考队列中位数”。预测也必须条件化到同一参考队列；不能把它冒充全体 NOIP 选手中位数。遮挡回测能检验恢复已知尾部的能力，不能证明真实获奖线以下的未知分布正确。

### 2. 按学校分组的样本外验证

同一学校的配对不同时出现在训练集与验证集。用截断条件概率的对数损失、已观测分位数校准及遮挡恢复误差选带宽/模型，不能使用普通获奖者 MSE 来挑“未截断中位数”模型。

必要时做嵌套分组验证，避免一边选参数一边把同一批验证成绩当作最终独立证据。

### 3. 同一目标的稳健性

- 正态与厚尾 t 模型；
- 不同带宽；
- 严格匹配与额外模糊配对；
- 有/无可支持的省份、年级效应；
- 留一省、留一大学校；
- 官方门槛不确定时的合理上下变化。

不要求所有算法给出相同数字；只比较估计同一个条件中位数目标的模型。等级分类线保留作另一政策口径，不作为判错基准。

### 4. 不确定性分开报告

1. **同分离散范围**：全国计数跳跃造成。
2. **模型条件的重抽区间**：省内按学校成组重抽配对并重拟合，分母与官方全国分数表固定；必要时重新选带宽。约 1000 次，不因增加抽样次数宣称新增数据。
3. **模型/缺失敏感性范围**：不同通过验证的分布假设、π 情景、门槛不确定性。它不是同一种 95% 置信区间。
4. **个人表现分散**：边界人群 NOIP 成绩的四分位区间，与“估计中位数有多准确”分开展示。

多年数据用来重复验证算法是否稳健；各年试卷不同，不直接混合原分，不因为年份为 2022 就自动判 C 级，也不因某年样本多而覆盖其他年份的结果。

## 六、本轮用现有数据做的实际检查

仅作诊断，不是新模型的正式推荐比例。

2025 年用 CSP-S 6级15%、7级7.5%，严格身份匹配，以各自同分块中点为中心取前后各 2 个百分点，且 NOIP 分数严格大于 86：

| 等级 | CSP-S 分数线 | 可见配对人数 | 可见 NOIP 成绩中位数 | 该分数以上的全国人数 | 对应全国比例 |
|---|---:|---:|---:|---:|---:|
| 6级 | 156 | 460 | 120 | 2462 | 32.62% |
| 7级 | 206 | 631 | 132 | 1761 | 23.33% |

改变局部窗口后，可见中位数相对稳定：6级约118～120分，7级约132～133分。但这只说明**可见人群内部**稳定，不说明未获奖截断偏差已经很小。

用上面的 π 公式作纯情景演示：

| 假设的边界低于共同门槛比例 π | 6级候选分数/对应比例 | 7级候选分数/对应比例 |
|---|---:|---:|
| 0% | 120 / 32.62% | 132 / 23.33% |
| 10% | 114 / 36.29% | 128 / 26.07% |
| 20% | 110 / 39.85% | 123 / 30.21% |
| 30% | 107 / 43.97% | 116 / 34.71% |
| 40% | 100 / 54.76% | 108 / 43.42% |

这些 π 是人为情景，不是由数据测得；使用窗口内经验分布、尚未做局部斜率或省份修正。这张表证明“处理可见获奖样本的截断”比单纯增加 bootstrap 次数更值得优先研究，而不是证明应该采用哪一行。

## 七、程序和 GUI 的建议结果结构

每级展示：

| 栏目 | 内容 |
|---|---|
| 全国 CSP-S 锚点 | 目标比例、分数线、同分范围、观测覆盖证明 |
| 边界样本 | 窗口、严格配对人数、有效样本量、学校/省份覆盖 |
| 直接可见结果 | 局部获奖者中位数与对应全国比例，明确注明条件人群 |
| 截断校正候选 | 分数线、全国比例、模型假设、估计 π、支持范围 |
| 验证表现 | 人工遮挡恢复误差、分组验证损失、带宽稳定性 |
| 不确定性 | 同分范围、模型条件重抽区间、模型敏感性分别列出 |
| 无法识别风险 | 截断严重程度、身份缺失、门槛缺失及未覆盖人群 |

取消“不同目标的方法差10个百分点即整体C级”的单一规则。改为分别报告资料核验质量、身份匹配质量、同一估计目标的稳定性和缺失假设依赖度，避免一个字母掩盖真正的问题。

## 八、实施顺序与止损标准

1. 核对并接入已有官方获奖门槛，统一身份匹配与分母口径；不再上网补数。
2. 实现局部可见中位数基线、同分处理和 π 敏感性表。
3. 实现简洁的截断条件分布模型，用人工遮挡和分组验证选择参数。
4. **只有当校正方法在预先约定的回测中优于直接基线，且跨分布/带宽稳定时，才把它放到主推荐栏。**这仍是模型条件估计，不是无条件证明。
5. 如果模型对未知尾部过于敏感，输出可见基线＋假设范围，并明确“当前数据不能支持唯一比例”；不自动回退到名额分摊，不用强行提高质量等级来掩盖问题。
6. 完成再重新计算正式结果。当前程序的34.71%/26.07%以及本文件的可见基线都不应提前被当作新方案的最终答案。
