# 局部标定 v3：实现与核验结果

## 实现状态

已完成“边界局部标定＋官方获奖截断校正＋学校分组遮挡验证”。本轮不再获取新数据，不修改原始获奖名单、全国总人数或名额数据。

- 主样本为严格同年同人配对；模糊配对只用于敏感性分析。
- 在 CSP-S 等级边界附近比较 ±1/2/3/5 个百分点窗口，以局部线性中位数作为可见基线。
- 使用分省官方获奖门槛拟合有界正态及厚尾 t(5) 条件截断分布。
- 学校分组验证选模型，独立学校审计集进行人工遮挡检查；比较同一审计选手、实际 CSP-S 分数和原门槛下的逐人中位数预测 MAE。
- 固定模型的学校重抽区间、同目标模型敏感性、未知低分比例π情景分开报告。
- 不再以不同估计目标的方法差异给数据打 A/B/C 总分。

## 2025 年正式样例

输入：CSP-S 6级前15%、7级前7.5%；seed=2026；每级1000次学校整组重抽；附加模糊配对敏感性。

| 指标 | 6级 | 7级 |
|---|---:|---:|
| CSP-S 分数锚点 | 156 | 206 |
| 采用的局部半窗口 | 5个百分点 | 5个百分点 |
| 局部严格配对数 | 1,171 | 1,538 |
| 有效样本量 | 830.51 | 1,102.35 |
| 学校数 | 485 | 428 |
| 可见基线模型线 | 118分 | 132.47分 |
| 可见基线全国累计比例 | **33.69%** | **22.31%** |
| 校正候选模型线 | 112.66分 | 122.23分 |
| 校正候选全国累计比例 | **37.20%** | **30.21%** |
| 校正候选的95%模型条件重抽区间 | 35.60%～38.99% | 26.74%～33.28% |
| 可见基线的95%近似重抽区间 | 30.84%～34.71% | 21.38%～23.78% |
| 两类重抽有效次数 | 1000/1000 | 1000/1000 |
| 是否采用校正作主推荐 | **否** | **否** |

说明：以“成绩≥模型线”计数。7级基线132.47分在现有整数成绩上等价于至少133分；6级校正112.66分等价于至少113分，7级校正122.23分等价于至少123分。程序不会为了凑比例把模型线随意下调到另一个分数。

### 不采用的具体依据

| 检查 | 6级 | 7级 |
|---|---:|---:|
| 朴素方法审计预测 MAE | 18.78分 | 25.19分 |
| 校正方法审计预测 MAE | 17.03分 | 20.29分 |
| 改善比例 | 9.34% | 19.48% |
| 通过预设遮挡改善门槛 | 否（不足10%） | 是 |
| 同目标、相近验证表现模型的比例范围 | 35.60%～48.56% | 27.40%～48.12% |
| 通过5个百分点稳定性门槛 | 否 | 否 |

这里的10%、0.5分和5个百分点是事先写入程序的**操作性采用标准**，不是官方标准，也不等于一种普遍最优的统计定理。

结论：校正已实现且有一定预测改善，但对未知尾部分布仍敏感。因此程序展示可见基线和校正候选，不把任一候选宣称为已经确定的全国最佳等级比例。

重抽区间固定已选分布和窗口，不含模型选择或未知缺失机制的不确定性。6级局部样本中甘肃、7级中宁夏只有一所学校，分别占约0.14%、0.06%的局部权重；这些分层无法估计组间重抽变异，已在报告中注明。

完整参数、每个候选、每次遮挡深度、门槛来源与诊断见 [正式 JSON 报告](../reports/local_2025_final.json)。

## 验证清单

- **47项单元/回归测试通过**：包含身份冲突、同分块复用、零获奖省份、未知官方门槛、极端正态尾概率、分组审计目标一致性、不可计数竞争模型、退化重抽分层，以及 GUI 任务队列和输入校验。
- **2020—2025 六年集成检查通过**，JSON 均能严格序列化，不输出 NaN。
- 2024 年发现1条完全重复的 CSP-S 记录，在内存中只计一次并输出去重提示；源文件未改动。
- **真实 GUI 操作通过**：点击计算、切换页签、复制完整报告、导出 JSON、悬停查看图值、重置。截图经过查看，未使用网页代替实际 tkinter 窗口。
- 图表两种固定级别颜色已通过浅色背景、对比度及色觉缺陷区分度验证。
- 缺少依赖时的提示、CLI 拒绝覆盖文件、Windows 启动脚本帮助均已检查。

GUI 截图检查使用0次重抽缩短等待；正式区间来自独立 CLI 的1000次运行，二者没有混淆。
