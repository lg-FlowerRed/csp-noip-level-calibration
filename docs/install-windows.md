# 安装与使用：CSP-S / NOIP 局部标定

## 环境

推荐 Windows 官方 Python 3.12（包含 Tcl/Tk）。计算依赖 **NumPy、SciPy**，界面使用 tkinter。

本机已经安装 Python；从旧版升级时，在程序目录执行一次：

```bash
py -m pip install -r requirements.txt
```

若尚未安装 Python，可运行本目录的 `install_python.bat`。它会检测 Python、按需要安装，并补齐 `requirements.txt` 中的依赖。请只运行自己信任的脚本；单位设备受策略限制时联系管理员。

## 图形界面

双击 [run_gui.bat](run_gui.bat)。程序文件应保持在同一目录：

- `calc_rating_gui.py`：界面；
- `calc_rating_matched.py`：分析流程、报告与命令行；
- `rating_records.py`：数据读取与同人匹配；
- `rating_local.py`：局部中位数、截断似然、验证与重抽；
- `requirements.txt` 和完整 `data/`。

输入年份、CSP-S 6级和7级累计比例，例如 **15** 和 **7.5**。GUI 输入框的单位始终是百分数：填 `0.5` 表示 `0.5%`。

- **开始标定**：严格同年同人匹配，计算两级基线与校正候选。
- **取消计算**：在当前一次拟合结束后取消，保留上一份报告。
- **复制完整报告 / 导出报告**：包含全部结论、门槛、模型、回测、敏感性和方法限制；可导出 UTF-8 文本或 JSON。
- **附加模糊匹配敏感性**：仅比较加入模糊候选后的变化，不改变主分析的严格配对样本。
- **重抽次数**：默认1000；填0跳过区间，但仍进行分组和遮挡验证。正式分析可能需要几分钟，计算期间界面仍可响应。

六个页签分别是：结论、模型与验证、敏感性、数据与门槛、方法与限制、图形核对。图中悬停可查看分数或假设情景；图表数值与文字报告共用同一结果。

## 命令行

双击 [run_calc.bat](run_calc.bat)，或执行：

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 1000
```

只做快速计算、不生成重抽区间：

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 0
```

输出结构化报告（拒绝覆盖已有文件，重复运行请换文件名）：

```bash
py calc_rating_matched.py --year 2025 --q-s-6 15 --q-s-7 7.5 --bootstrap 1000 --json --output NOIP2025-local.json
```

命令行保留旧版小数输入兼容：`15`、`15%`、`0.15` 均表示15%；`1` 表示1%。不足1%的比例建议明确带 `%`，如 `--q-s-7 0.5%`，避免单位歧义。

`--seed 2026` 控制学校划分与重抽的可重复性。`--match-mode fuzzy` 只开启额外的模糊配对敏感性。

## 怎样解读新版结果

**可见基线**：严格配对且能看到 NOIP 成绩的获奖者，在 CSP-S 等级边界处的局部线性中位数。它不是已校正的全体参赛者中位数。

**校正候选**：按各省官方获奖门槛拟合的截断条件分布，给出完整边界人群的模型条件中位数。比较有界正态和厚尾 t(5)，窗口半宽为1、2、3、5个百分点。

**采用判断**：只在学校分组/人工遮挡验证、有效样本、同目标模型稳定性和全国计数覆盖均通过时采用校正。未通过时显示两者及原因，不用一个 A/B/C 字母评价全部数据，更不会把可见基线冒充唯一全国建议。

**三种不确定性不要混淆**：

1. 同分范围：固定分数线的严格高于/包含同分计数；
2. 95%近似重抽区间：固定所选分布与窗口、按学校整组重抽；
3. 模型与缺失敏感性：不同模型及人为设定的低分缺失比例π的影响，不是另一条95%区间。

人工遮挡验证只在原本已经可见的队列内进行：使用每名审计选手的实际 CSP-S 分数及原获奖门槛，比较逐人中位数预测 MAE，不把不同定义的汇总位置相互比较。它不能证明真实获奖线以下的分布。原始名单不含未获奖者身份，未匹配记录不会被自动填成0分或未获奖。省内只有一所学校的分层不提供组间重抽方差；如果全部分层都如此，程序不会报告虚假的零宽区间。

## 本地数据要求

- `data/contests.json`：全国实际参赛人数及满分；
- `data/raw.txt`：完整获奖名单；
- `data/school.txt`：学校别名；
- `data/province_cutoffs.json`：已收集的官方分省获奖门槛。

门槛缺失的年份仍显示可见基线与已知人数下界，但不猜测最低获奖线。`province_participants.csv` 的估算人数和 `province_quotas.json` 的名额 **不参与主计算**。

完全相同的重复行只计一次并记录去重数；源文件保持不变。身份相同但分数等字段冲突的记录不会强行链接。

## 常见问题

- **缺少 NumPy / SciPy**：运行本文开头的依赖安装命令。
- **缺少 tkinter / Tcl-Tk**：重新运行官方 Python 安装器，添加 Tcl/Tk 组件；pip不能替代该组件。
- **显示“未采用校正”**：看“采用理由”和“模型与验证”，不代表所有数据无效；常见原因是不同合理分布仍给出明显不同的候选比例。
- **旧的34.71%等结果发生变化**：旧版估计平均百分位，新版主目标是条件中位数，并使用官方门槛；两个结果不是同一估计量。
- **0次没有置信区间**：这是明确跳过区间，而非计算错误。

旧 [calc_rating_percentage.py](../legacy/calc_rating_percentage.py) 仅作历史归档，不由新版界面调用。详细原理见 [局部标定改进方案](method-v3-local-calibration.md)。
