# 数据目录说明

本目录只发布**不含个人信息**的聚合数据。运行完整分析还需要两份未随仓库发布的文件。

## 已发布

| 文件 | 说明 |
|---|---|
| `contests.json` | 赛事名称、年份、满分、全国实际参赛人数 `capacity` |
| `province_cutoffs.json` / `.csv` | 分省一/二/三等奖分数线与人数，含来源 URL |
| `province_quotas.json` | NOIP 分省 A/B 类参赛名额 |
| `province_participants.csv` | 名额上限及按全国比例分摊的估算，**不是官方分省人数** |
| `province_awards_from_raw.csv` | 逐省逐奖人数、实际最低/最高获奖分，无姓名 |
| `分省数据说明.md` | 口径、来源、缺口与后续补数建议 |

## 需要自行提供

| 文件 | 格式 | 用途 |
|---|---|---|
| `raw.txt` | `赛事,奖项,姓名,年级,学校,分数,省份,性别,备注` | 完整获奖名单；同人匹配与分数分析 |
| `school.txt` | `省,市,正式校名,别名...` | 学校别名归一 |
| `grades.json`、`surnames.json`、`name_exceptions.json`、`scoring.json` | 上游辅助映射 | 当前主程序不读取，可省略 |

获取方式：从 NOI 官网公布的各年获奖名单整理，或使用你已有且有权使用的数据集。请自行确认个人信息保护与上游许可要求。

## 为什么不在仓库里

`raw.txt` 含姓名、学校、年级、分数等可识别信息，且大量主体为未成年人；`school.txt` 与部分辅助文件疑似来自第三方数据集。公开仓库不适合二次发布这些内容。

## 缺少数据时

- 真实数据集成测试会自动跳过；
- 合成数据测试仍可运行；
- CLI/GUI 在缺少 `raw.txt` 或 `school.txt` 时会给出明确错误，不会用估算数据代替。
